# Website Prototype Contract V1

Website prototype artifacts are draft-only JSON documents. They can describe page structure, proof blocks, and lead-capture placeholders, but they do not create hosting, DNS, VPS, browser, form submit, or production write actions.

Required safety fields:

- `draft_only=true`;
- `deployment_allowed=false`;
- `hosting_allowed=false`;
- `dns_change_allowed=false`;
- `form_submit_allowed=false`;
- owner approval required for future deploy or send.

Every factual claim requires evidence.
