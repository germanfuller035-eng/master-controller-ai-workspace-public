# Website Analysis Contract V1

Website quality is scored from synthetic fixture metrics only:

- response time;
- mobile readiness;
- message clarity;
- trust proof count;
- lead capture readiness.

The score is deterministic and does not use browser automation, crawling, LLM calls, or provider credentials.

Output claims must be evidence-backed. QA / Red Team blocks missing evidence, unsupported language, deploy recommendations without owner approval, form submit, outbound, and production write recommendations.
