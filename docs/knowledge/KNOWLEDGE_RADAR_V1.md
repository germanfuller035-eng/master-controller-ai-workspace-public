# Knowledge Radar V1

Knowledge Radar is proposal-only in this session.

Allowed:

- create local synthetic proposals
- classify proposal reason
- attach source_id, created_at, confidence, and classification
- deny unsafe actions deterministically

Denied:

- install components
- crawler
- browser automation
- real GitHub polling
- legal, tax, or government source monitoring
- external network
- production automation
- memory write
- production DB write

Knowledge Radar cannot activate itself. Future activation requires an owner
approved stage with source allowlists, monitoring policy, rollback, and security
review.
