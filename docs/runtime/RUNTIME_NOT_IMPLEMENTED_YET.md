# Runtime Not Implemented Yet

Explicitly not implemented in this session:

- VoltAgent installation;
- public VoltAgent API;
- managed VoltAgent memory;
- production VoltAgent runtime;
- real LLM calls;
- provider credentials;
- persistent memory;
- production MCP tool calls;
- external MCP servers;
- Qdrant;
- OPA runtime;
- Infisical;
- OpenTelemetry, Grafana, Tempo, Loki, or Prometheus stack;
- browser automation service;
- production tool adapters;
- autonomous outbound systems;
- production deploy;
- production DB write;
- VPS change;
- Android acceptance, APK install, Full Run 1, or Full Run 2.

Default production rule remains `AGENT_RUNTIME=OFF`.
