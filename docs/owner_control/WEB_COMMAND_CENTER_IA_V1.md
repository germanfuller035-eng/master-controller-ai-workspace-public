# Web Command Center IA V1

Web Command Center sections:

- Today & Decisions: morning summary, one main action, urgent approval queue, STOP state.
- Commerce: commercial funnel, leads, offer preview, replies, deals, no-send state.
- AI Circuit: agents, workflows, approvals, risk copy, synthetic execution evidence.
- Knowledge: knowledge status, memory proposal review, source evidence, no direct memory write.
- System: costs, budgets, incidents, feature flags, STOP, health, rollback notes.

The IA is display and decision support only. It does not deploy Web UI, write production data, send messages, run payments, or execute approvals.

Feature flags are shown as OFF, LOCAL_SYNTHETIC, or future states. The panel is read-only and cannot enable production flags.
