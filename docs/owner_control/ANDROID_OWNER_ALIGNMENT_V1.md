# Android Owner Alignment V1

Android remains the primary mobile owner control interface. Web Command Center aligns to Android by using the same owner-facing concepts and safe defaults.

Required aligned surfaces:

- Today
- Approvals
- Leads
- Offer Preview
- Replies
- Deals
- Agents
- Costs
- Incidents
- Memory proposals
- Global STOP
- Voice

Web shows broader desktop review and evidence context. Android stays optimized for mobile owner control. Neither surface sends, deploys, pays, writes production data, or captures real voice in this stage.
