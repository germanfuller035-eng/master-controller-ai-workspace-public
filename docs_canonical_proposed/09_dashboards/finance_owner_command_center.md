# Owner Financial Command Center (canonical)

> Owner daily/weekly/monthly financial action view. No real notifications.

## Daily
overdue receivables · payments needing confirmation · unexpected expenses · cash warnings · blocked project payments.

## Weekly
expected receipts · bills · cash runway · project margins · owner workload · budget variance · reserve shortfall.

## Monthly
close · P&L · cashflow · budget · tax reserve · product economics · business-unit decisions.

## Current state
- No live data → most fields UNKNOWN until owner provides cash balances, capacity, and confirms payments.
- Alerts are recommendations only (no external messages).
