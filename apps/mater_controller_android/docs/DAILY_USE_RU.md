# Mater Controller — ежедневная работа (RU)

Короткий сценарий на каждый день. Никаких slash-команд, JSON, VS Code или PowerShell —
только приложение.

## Каждый день

1. Открой **Mater Controller** на телефоне.
2. Вкладка **Сегодня**:
   - проверь индикатор «API доступен»;
   - посмотри карточку **Следующее действие**.
3. Открой **Следующее действие** или зайди во вкладку **Проекты → Mini Audit**.
4. В **Mini Audit** выбери нужную категорию:
   - **✅ Готовы к отправке** — лиды, готовые к письму;
   - **📬 Ожидают ответа** — уже отправленные (Завод Атом, СтройДвор-Юг, ДКБИ);
   - **🔁 Follow-up** — напоминания по доказанным отправкам;
   - **⚠️ Требуют проверки** / **🧾 Неопределённые отправки**.
5. Открой карточку лида:
   - вкладка **Аудит** — проверь текст аудита;
   - вкладка **Письмо** — проверь получателя, тему и текст.
6. Если лид готов — нажми **Подтвердить отправку**:
   - появится финальное окно с компанией, email, темой и предупреждением о реальной отправке;
   - нажми **Отправить письмо**, чтобы отправить, или **Отмена**, чтобы отклонить.
7. Проверь **Ожидают ответа** и **Follow-up**, чтобы ничего не потерять.

## Что важно

- **Автоотправка отключена.** Письмо уходит только после твоего подтверждения.
- Неопределённые отправки (`send_uncertain`) не отправляются повторно автоматически —
  только проверка доказательства.
- Telegram остаётся резервным каналом уведомлений и аварийного подтверждения.
- Офлайн показывает последние загруженные данные; отправка офлайн недоступна.
