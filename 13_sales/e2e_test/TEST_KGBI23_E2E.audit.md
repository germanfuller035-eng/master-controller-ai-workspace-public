## Объект
- Компания: КЖБИ (по данным сайта), производство ЖБИ/бетона.
- Сайт: https://kgbi23.ru (DNS 176.57.65.75, HTTPS 200, за ddos-guard).
- Регион: Краснодарский край (Славянск-на-Кубани, ул. Зеленского 1а — по данным сайта).
- Проверка: прямой HTTPS-запрос + анализ HTML 2026-06-16.

## Findings (только evidence-backed; без догадок о выручке/владельце/проблемах)

1. **HTTPS работает, но сайт за ddos-guard challenge** — evidence: ответ `Server: ddos-guard`,
   set-cookie `__ddg*`. Implication: часть ботов-краулеров и превью-сервисов (напр. внешний
   рендер) может блокироваться, что снижает индексируемость/превью в мессенджерах.
   (Факт сети, не гарантия проблем SEO.)

2. **Контактный email на сайте — на домене mail.ru, не на собственном домене** —
   evidence: `mailto:kgbi2020@mail.ru`. Implication: письма с делового домена воспринимаются
   как более доверенные; почта на mail.ru снижает узнаваемость бренда в переписке.

3. **Несколько телефонов без единого приоритетного CTA-номера** — evidence:
   `tel:+79180527777`, `tel:78614631106`, `tel:78614631125`. Implication: пользователю
   неочевидно, куда звонить по заявке; разнобой форматов (+7 и 8) ухудшает клик-到-звонок на мобильных.

4. **Мобильный viewport присутствует** — evidence: `<meta name="viewport" content="width=device-width, initial-scale=1.0">`.
   Это плюс; отдельная проверка реальной верстки на устройстве не проводилась (не выдумываем).

5. **Контактные формы есть (2 шт.)** — evidence: 2 тега `<form>` в HTML. Implication: канал
   заявок существует; стоит проверить, что обе ведут в один обработанный поток лидов (не дубли).

6. **Большой вес страницы (~850 КБ HTML)** — evidence: размер документа 870192 байт.
   Implication: тяжёлый первичный HTML может замедлять открытие на слабом мобильном интернете;
   стоит проверить реальную скорость (метрика не измерялась здесь — не утверждаем число).

## 7-дневный план действий (gример, без гарантий результата)
- День 1–2: вынести один приоритетный телефон и единый формат +7 в шапку.
- День 3–4: добавить деловой email на собственном домене для исходящих КП.
- День 5: проверить, что обе формы идут в один список заявок без дублей.
- День 6–7: измерить реальную скорость мобильной загрузки и при необходимости облегчить первый экран.
