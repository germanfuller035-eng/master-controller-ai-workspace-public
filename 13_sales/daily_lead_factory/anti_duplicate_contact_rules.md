# ANTI-DUPLICATE CONTACT RULES

**Версия:** 1.2 (расширены правила: 14-day cap, personal WA, auto-send)  
**Дата:** 2026-05-26  
**Проект:** Mini Audit 10K / Daily Lead Factory  
**Приоритет:** КРИТИЧЕСКИ ВАЖНО — нарушение = репутационный ущерб

---

## Общие принципы

1. **Один лид — один активный диалог** в любой момент времени.
2. **Дедупликация по ключам** перед каждым касанием.
3. **Лог каждого касания** — обязателен.
4. **do_not_contact = true** → немедленный стоп по всем каналам.
5. **Все касания — только ручные, с approval.**

---

## Дедупликация по каналам

### Email
- Дедупликация по `email` (нормализованный lowercase)
- Не отправлять, если `last_contact_date < 48h` назад
- Не отправлять повторно тот же шаблон тому же адресу

### WhatsApp
- Дедупликация по `phone` (нормализованный, без пробелов/скобок, с кодом страны)
- Не писать в WhatsApp, если email отправлен < 24h назад
- Не писать в WhatsApp и Telegram в один день

### Telegram
- Дедупликация по `telegram_username` / `telegram_id`
- Не писать в Telegram если WhatsApp-сообщение отправлено в тот же день
- Не писать в Telegram, если уже есть активный диалог

### MAX Messenger
- **Дедупликация по:** `max_id` / `phone` / `company` / `domain`
- **Не писать в MAX, если:**
  - `do_not_contact = true` (любое основание)
  - `last_contact_date < 48h` назад (любой канал)
  - В тот же день уже было WhatsApp или Telegram касание
  - Контакт получен из неопределённого источника (нет публичного основания)
  - Уже было 3 или более MAX-касания по этому контакту
- **Не писать с личного MAX-аккаунта**, если есть рабочий канал/бот

### Телефон
- Дедупликация по `phone`
- Только после минимум 1 попытки по другому каналу
- Не звонить без предварительного email-касания

## Правила across-channel (между каналами)

| Условие | Действие |
|---|---|
| Email + WhatsApp в один день | ❌ Нельзя — только один канал в день |
| WhatsApp + MAX в один день | ❌ Нельзя |
| Telegram + MAX в один день | ❌ Нельзя |
| Email → WhatsApp follow-up | ✅ Можно, минимум 48h после email |
| Email → MAX follow-up | ✅ Можно, если есть публичный MAX-контакт, минимум 48h |
| WhatsApp → MAX | ✅ Можно, если WhatsApp без ответа 48h+ |
| 3+ касания без ответа | → `hold_30d` автоматически |
| Явный отказ в любом канале | → `do_not_contact` немедленно |

## Максимальное количество касаний на контакт

| Канал | Макс. касаний |
|---|---|
| Email | 3 (initial + value followup + close-loop) |
| WhatsApp | 2 (initial + 1 follow-up) |
| Telegram | 2 (initial + 1 follow-up) |
| **MAX** | **3 (initial + 1 follow-up + 1 close-loop)** |
| Телефон | 1–2 (не более 2 звонков) |
| **Итого по контакту** | **Не более 7–9 касаний за весь цикл** |

## Проверка перед отправкой (чеклист)

```
□ do_not_contact != true
□ Дата последнего касания (любой канал) > 48h назад
□ Количество касаний по целевому каналу < максимума
□ Нет другого касания сегодня по другому мессенджеру
□ Публичное основание для MAX (если MAX)
□ Approval получен
□ Шаблон персонализирован (нет незаменённых [placeholder])
□ Логирование готово
```

---

## MAX-специфичные проверки

```
□ max_contact_source = public (сайт/QR/канал/явная просьба клиента)
□ max_touch_count < 3
□ last_max_contact > 48h назад
□ no_whatsapp_today = true
□ no_telegram_today = true
□ personal_account_check: использовать рабочий канал, не личный MAX
```

## Комментарии к ключевым правилам

### Правило 5: Max 4–5 касаний за 14 дней
Полный цикл follow-up: Day 0 (email) + Day 2–3 (WA) + Day 5–6 (value) + Day 9–10 (close-loop) = 4 касания.  
5-е касание только при наличии значимого триггера (ответ, событие, новость по компании).  
После 5 касаний без ответа → `hold_30d` автоматически.

### Правило 6: No auto-send without Дмитрий approval
Ни один шаблон не отправляется без явного [APPROVED] от Дмитрия.  
Касается всех каналов: Email, WhatsApp, MAX, Telegram, Phone.  
Нет approval = нет отправки = нет исключений.

### Правило 7: No personal WhatsApp for business
Личный номер телефона Дмитрия не используется для B2B-аутрич.  
Только WhatsApp Business с бизнес-профилем.  
Смешивание личного и рабочего WhatsApp — риск репутации.
