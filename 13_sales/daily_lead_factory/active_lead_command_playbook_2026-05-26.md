## Как использовать

1. Найти лида в таблице ниже
2. Скопировать команду из колонки "Команда для Cline"
3. Вставить в Cline (чат VS Code)
4. После выполнения и ручной отправки — использовать команду логирования

## Что никогда не делать через Cline

- ❌ НЕ отправлять сообщения клиентам напрямую
- ❌ НЕ читать .env, пароли, токены
- ❌ НЕ запускать VPS/SSH/deploy
- ❌ НЕ делать bulk outreach без approval
- ❌ НЕ подключаться к Telegram-боту для отправки клиентам

---

## Порядок работы

```
Dashboard (смотреть) 
  → Cline (подготовить черновик) 
  → Дмитрий (одобрить) 
  → Ручная отправка (email/WA/TG/MAX) 
  → Cline (залогировать касание)
```
