## 3. Как пользоваться блоком «Активные лиды»

**Блок показывает 5 приоритетных лидов с карточками.**

Каждая карточка содержит:
- **Номер очереди** (1–5) — приоритет по важности/срочности
- **Название лида и ID** — короткий идентификатор
- **Статус** — текущее состояние лида (Ждём ответ / Активный / Тёплый лид и т.д.)
- **📌 Следующий шаг** — конкретное действие (дата + формат)
- **Можно писать сейчас** — всегда проверяй это поле. Если «Нет» — действий не делаем.
- **Канал** — через что будет контакт (email / WA Business / Telegram / …)
- **🚫 Что запрещено** — специфические запреты по этому лиду
- **Псевдокнопки** — подсказки следующего шага (см. п. 5)

**Правила чтения:**
1. Начинай с лида #1 (верхний).
2. Проверяй поле «Можно писать сейчас» — если «Нет», переходи к решениям Дмитрия.
3. Если «можно» — смотри «Следующий шаг» и нажимай (псевдо)кнопку.

---

## 4. Как пользоваться «Центром решений Дмитрия»

**Блок — операционная таблица решений, которые нужно принять Дмитрию.**

Колонки:
| Колонка | Смысл |
|---------|-------|
| # | Приоритет (1 = срочнее) |
| Лид | Название лида |
| Решение Дмитрия | Вопрос, на который нужен ответ |
| Варианты | Возможные варианты ответа |
| Что будет после решения | Что Cline сделает после получения ответа |

**Алгоритм работы с таблицей:**
1. Смотришь строку #1 → читаешь вопрос → выбираешь вариант → говоришь Cline.
2. Cline выполняет следующее действие (готовит черновик / ищет контакт / ставит HOLD).
3. После решения по лиду строка убирается или обновляется статус.

**Пример:**
- ZB23: «Ждать ответ до 2026-05-28» → вариант «ждать» → Cline ничего не делает до 28-го.
- ГСК: «Какой канал?» → Дмитрий говорит «WhatsApp» → Cline готовит WA draft.

## 5. Псевдокнопки — что это и как использовать

**Псевдокнопки НЕ отправляют сообщения.** Это визуальные подсказки.

| Кнопка | Смысл |
|--------|-------|
| 📬 Проверить ответ | Напоминание проверить Яндекс-почту или другой канал |
| 📝 Подготовить черновик | Cline готовит черновик после approval Дмитрия |
| 👤 Нужен контакт | Дмитрий предоставляет ЛПР / контакт |
| ✅ Ждёт решения Дмитрия | Лид заблокирован до принятия решения |
| ⏸ HOLD | Лид заморожен — нет действий |

**Как активировать действие по псевдокнопке:**
1. Видишь кнопку → понимаешь, что нужно сделать.
2. Говоришь Cline: «Подготовь черновик для ZB23 follow-up через WA Business».
3. Cline готовит черновик → ты смотришь → даёшь approval → только тогда отправляется.

**Hover-подсказка кнопки:** «Действие выполняется через Cline/Telegram после approval Дмитрия. Кнопка не отправляет сообщения.»

## 6. Архив истории касаний — справочно

**Блок «Архив истории касаний» свёрнут по умолчанию.**

⚠️ **Не использовать как рабочую очередь.**

- Содержит историю прошлых касаний (legacy leads, старые статусы).
- Данные не удалены — только скрыты с главного экрана.
- Рабочий статус лида смотреть ТОЛЬКО в блоке «Активные лиды».
- Раскрыть архив: нажать «📦 Архив истории касаний — справочно».

**Почему архив не рабочий:**
- Статусы в архиве могут быть устаревшими.
- По архивным лидам нет актуальных решений.
- Работать по архиву = риск задублировать контакт или написать не в то время.

## 8. Правила безопасности

- **Auto-send: ВЫКЛ** — всегда. Индикатор в шапке dashboard.
- Все отправки только через Cline с explicit approval Дмитрия.
- .env, токены, пароли — не читать, не трогать.
- VPS / SSH / deploy — не трогать через dashboard.
- Telegram-бот — не менять конфигурацию через dashboard.

## 10. Куда давать команды

> Ключевой раздел: объясняет разделение ролей между dashboard, Cline, ручными действиями и Telegram-ботом.

### Dashboard = СМОТРЕТЬ

- Dashboard показывает текущее состояние системы.
- Dashboard **не выполняет** действия — ни отправки, ни изменения статусов.
- Используй dashboard для принятия решений: смотришь → решаешь → идёшь в Cline.

### Cline = ВЫПОЛНЯТЬ ЗАДАЧИ В AI_WORKSPACE

- Все подготовительные задачи (черновики, проверка статусов, обновление данных) — через Cline.
- Cline работает внутри D:\AI_WORKSPACE — файлы, JSON, markdown.
- Cline **не отправляет** клиентам. Только готовит материалы.

**Как давать команду Cline:**
```
Подготовь follow-up draft для ZB23 канал WhatsApp Business по состоянию на 2026-05-28
```
```
Залогируй ручное касание по КЖБИ дата 2026-05-27 канал WhatsApp результат отправлено_первое_письмо
```
```
Обнови статус лида ГСК на active_draft_ready причина выбран канал email
```

Шаблоны команд: `02_templates/active_lead_cline_command_templates.md`

### Ручная почта / WA / MAX / TG = ОТПРАВЛЯТЬ КЛИЕНТУ

- Всё, что идёт клиенту — только вручную Дмитрием.
- Перед отправкой: запросить approval-карточку через Cline.
- После отправки: **обязательно залогировать** через Cline.

**Цепочка:**
```
Cline готовит черновик → Дмитрий читает → Дмитрий говорит "одобрено" → Дмитрий отправляет вручную → Дмитрий говорит Cline "залогируй касание"
```

### После ручного касания = ЛОГИРОВАТЬ через Cline

- После каждой ручной отправки обязательно сказать Cline:
```
Залогируй ручное касание по [ЛИД_ID] дата [ДАТА] канал [КАНАЛ] результат [РЕЗУЛЬТАТ]
```
- Без логирования данные в dashboard не обновятся.

### Telegram-бот = ПОЗЖЕ

- Telegram-бот **пока не подключён** к этим командам.
- Сейчас бот работает в тестовом режиме.
- Команды через Telegram-бота — следующий этап после стабилизации ручного цикла.
