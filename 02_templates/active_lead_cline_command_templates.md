# Active Lead Cline Command Templates

> Файл: `02_templates/active_lead_cline_command_templates.md`  
> Обновлён: 2026-05-26  
> Назначение: шаблоны команд для Cline по работе с активными лидами

---

## Как использовать шаблоны

1. Скопировать нужный шаблон
2. Заменить `[LEAD_ID]`, `[Название лида]`, `[канал]`, `[дата]`, `[результат]` на реальные данные
3. Вставить в Cline (окно чата VS Code)
4. Дождаться выполнения

---

## prepare_draft

**Назначение:** Подготовить черновик сообщения для лида (первое / follow-up / post-sale offer)

```
Подготовь [тип: первое сообщение / follow-up / post-sale offer] для лида [LEAD_ID] ([Название лида]).
Канал: [email / WhatsApp Business / Telegram].
Контекст: [краткое описание ситуации].
Шаблон: 02_templates/b2b_followup_message_templates.md
Сохрани черновик в: 13_sales/daily_lead_factory/output/draft_[LEAD_ID]_[дата].md
```

**Пример ZB23:**
```
Подготовь WhatsApp Business follow-up для лида ZB23 (Завод ЖЕЛЕЗОБЕТОН).
Канал: WhatsApp Business.
Контекст: отправили email 2026-05-26, ответа нет. Дата follow-up — после 2026-05-28.
Шаблон: 02_templates/b2b_followup_message_templates.md
```

## verify_contact

**Назначение:** Проверить / подтвердить контакт и канал связи для лида

```
Проверь и подтверди контакт для лида [LEAD_ID] ([Название лида]).
Дмитрий подтверждает ЛПР: [имя/должность/контакт].
Обнови contact_resolution.json.
Файл: data/contact_resolution.json
```

**Пример КЖБИ:**
```
Дмитрий подтверждает ЛПР для КЖБИ.
ЛПР: [имя], [должность], [телефон/email].
Обнови data/contact_resolution.json и 13_sales/daily_lead_factory/client_communication_status_map.md.
```

---

## verify_reply

**Назначение:** Проверить, пришёл ли ответ от лида

```
Проверь, пришёл ли ответ от [LEAD_ID] ([Название лида]).
Проверь: data/inbox_messages.json, data/reply_monitoring.json.
Дата последнего касания: [дата].
Отчёт: есть ответ / нет ответа / требует уточнения.
```

**Пример ZB23:**
```
Проверь, пришёл ли ответ от ZB23 (Завод ЖЕЛЕЗОБЕТОН) на Яндекс-почту.
Файл: data/inbox_messages.json
Дата отправки письма: 2026-05-26.
```

## log_manual_touch

**Назначение:** Залогировать ручное касание после отправки клиенту

```
Залогируй ручное касание:
- Лид: [LEAD_ID] — [Название лида]
- Канал: [email / WhatsApp Business / Telegram / MAX / телефон]
- Дата: [YYYY-MM-DD]
- Тип: [первое / follow-up / ответ на запрос / post-sale]
- Результат: [отправлено / прочитано / ответил / не ответил / недоступен]
- Примечание: [необязательно]

Запиши в: 13_sales/daily_lead_factory/output/outreach_log_[LEAD_ID]_[дата].md
Обнови: data/followups.json
```

**Пример ZB23:**
```
Залогируй ручное WhatsApp-касание ZB23 (Завод ЖЕЛЕЗОБЕТОН).
Канал: WhatsApp Business. Дата: 2026-05-29. Тип: follow-up.
Результат: отправлено, ответа нет.
```

## put_on_hold

**Назначение:** Поставить лида на hold — когда нет нужной информации для продолжения

```
Поставь лида [LEAD_ID] ([Название лида]) на hold.
Причина: [причина — нет контакта / нет ответа / ждём данных / нет approval].
Дата следующей проверки: [YYYY-MM-DD].
Обнови: data/leads.json (статус → HOLD), data/followups.json.
```

---

## approve_manual_send

**Назначение:** Дмитрий подтверждает, что черновик одобрен и можно отправлять вручную

```
Дмитрий одобряет отправку черновика для [LEAD_ID] ([Название лида]).
Черновик: [путь к файлу черновика или текст].
Канал: [email / WhatsApp Business / Telegram].
Действие: пометить в approval_queue.json как approved.
Запись в: data/approvals.json.
```

**После approval — Дмитрий отправляет вручную, потом логирует через log_manual_touch.**

## update_lead_status

**Назначение:** Обновить статус лида в системе после события

```
Обнови статус лида [LEAD_ID] ([Название лида]).
Новый статус: [WAITING_REPLY / ACTIVE / HOLD / CLOSED_WON / CLOSED_LOST / RENEGOTIATION].
Причина изменения: [описание события].
Обнови: data/leads.json, data/followups.json.
Запись в events_log: [описание для лога].
```

## Сводная таблица шаблонов

| Template | Когда использовать | Требует approval |
|---|---|---|
| `prepare_draft` | Нужен черновик для отправки | Да — перед ручной отправкой |
| `verify_contact` | Нет подтверждённого контакта/ЛПР | Да — данные даёт Дмитрий |
| `verify_reply` | Проверить ответ от клиента | Нет |
| `log_manual_touch` | После любой ручной отправки | Нет |
| `put_on_hold` | Нет данных для продолжения | Нет |
| `approve_manual_send` | Дмитрий одобряет черновик | Да — это и есть approval |
| `update_lead_status` | Изменился статус лида | Нет (фиксация факта) |
