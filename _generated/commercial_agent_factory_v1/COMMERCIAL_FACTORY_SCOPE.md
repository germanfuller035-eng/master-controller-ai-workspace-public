# Commercial Factory Scope

Allowed in this stage:

- local deterministic commercial contracts
- synthetic fixtures only
- draft-only no-send offer objects
- synthetic digital presence fixtures
- local validators and unit tests
- local evidence, rollback, and handoff docs

Forbidden in this stage:

- outbound email, social, form, publication, invoice, payment, or phone action
- real lead scraping, crawling, browser automation, or real customer contact
- production DB write, CRM write, VPS change, deployment, merge, tag, release
- real Qdrant, real Docling, crawler runtime, external MCP server, mail integration with send permission
- real client, personal, medical, military, credential, runtime, or production data in fixtures

Default rule: no send, no production write, no external outreach.
