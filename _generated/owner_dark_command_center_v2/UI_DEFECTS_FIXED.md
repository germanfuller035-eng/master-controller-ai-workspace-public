# UI Defects Fixed

Fixed:
- Default app theme is dark command center style.
- Bottom navigation replaced by owner drawer and focus/overview top controls.
- Command bar now executes local commands through Done/Enter and clears focus before execution.
- Channel selection no longer renders as a long prose wall.
- Channel selection no longer confuses recipient with selected channel.
- Manual channel can create a packet without pretending it is email.
- Drawer shortcut "Первый ручной пакет" now opens the send packet route.
- Send packet screen clearly shows not-sent state and package/text markers.
