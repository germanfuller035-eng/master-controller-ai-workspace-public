
## Owner Approval Gate

Before any manual send, confirm:

- The offer uses verified facts.
- The value statement is framed as an estimate or hypothesis when needed.
- The risks and non-promises are explicit.
- No automatic send path was used.
- Owner approval is recorded outside the repo.
