# Mini Audit Landing — Publication Package
Landing scaffold is BUILT_NOT_PUBLISHED. To publish: approve a domain, point it at the public intake
API (/api/v1/public/intake, /api/v1/public/mini-audit-request), set WEB_LANDING publish flag, and add
the privacy notice. Price comes from the Product OS snapshot via API (never hardcoded). No external
tracking without approval.
