## Назначение

Операционная процедура мониторинга ответов клиентов на outreach-письма в рамках кампании Mini Audit 10K. Документирует ежедневные действия по проверке входящих, классификации ответов и обновлению статусов лидов.

---

## 1. Ежедневная проверка входящих

**Время проверки:** 1 раз в день (рекомендовано утром, до 12:00 МСК)  
**Метод:** Ручная проверка Яндекс.Почты

### 1.1 Шаги проверки

1. **Открыть** Яндекс.Почту → mail.yandex.ru
2. **Папка Входящие:**
   - Отсортировать по дате (новые сверху)
   - Найти письма от доменов лидов из активной очереди
3. **Папка Спам:**
   - Проверить на предмет ответов, попавших в спам
   - Особенно актуально для неизвестных отправителей
4. **Папка Удалённые:**
   - Проверить при необходимости (редко)
5. **Зафиксировать результат:**
   - Если ответ найден → перейти к разделу 3
   - Если ответа нет → перейти к разделу 4

## 2. Поиск ответов по From / Subject / Message-ID / domain

### 2.1 Поиск по домену клиента

В строке поиска Яндекс.Почты:
```
from:zb23.ru
from:@zb23.ru
```

### 2.2 Поиск по теме письма

```
subject:"Re: Бесплатный аудит сайта"
subject:Re:
```

### 2.3 Поиск по дате

Фильтр: письма **после** даты отправки outreach (после 2026-05-26 09:19 МСК для ZB23)

### 2.4 Проверка заголовков (Message-ID / In-Reply-To)

При наличии подозрительно похожего письма:
1. Открыть письмо
2. Меню → "Свойства письма" / "Показать источник"
3. Проверить наличие заголовка `In-Reply-To:` — это ответ на наше письмо
4. Сравнить `Message-ID` исходного письма с `In-Reply-To` ответа

|---|---|---|---|

## 3. Обновление статуса лида

### 3.1 Статусы и критерии

#### `reply_positive`
**Условие:** Клиент ответил с интересом  
**Признаки ответа:**
- "Пришлите подробнее"
- "Расскажите о ценах"
- "Сколько стоит?"
- "Интересно, давайте обсудим"
- "Когда можно созвониться?"
- Любой вопрос или проявление интереса

**Действия:**
1. Обновить статус в `leads_master.json` → `reply_positive`
2. Установить `reply_received: true`, `reply_type: positive`
3. Зафиксировать дату ответа в `last_reply_date`
4. Подготовить черновик ответа → `draft_path`
5. Добавить в `followup_queue` с `priority: high`
6. **Немедленно уведомить Дмитрия** — это горячий лид!
7. Ждать одобрения перед отправкой

---

#### `reply_negative`
**Условие:** Клиент явно отказал  
**Признаки:**
- "Не интересно"
- "Не нужно"
- "Мы уже работаем с другими"
- "Больше не пишите"
- "Удалите мой адрес"

**Действия:**
1. Обновить статус в `leads_master.json` → `reply_negative`
2. Установить `do_not_contact: true`
3. Добавить в `lead_blacklist.json` (если явный отказ от контакта)
4. Удалить из активной follow-up очереди
5. Зафиксировать причину в `notes`
6. **Не отправлять** больше никаких сообщений

---

#### `waiting_reply`
**Условие:** Письмо отправлено, срок ответа ещё не истёк  
**Применяется:** Пока не истекло время ожидания (обычно 48ч после отправки)

**Действия:**
1. Оставить статус `waiting_reply`
2. Убедиться, что `next_contact_date` установлена
3. Не трогать лид до наступления `next_contact_date`

---

#### `followup_due`
**Условие:** Дата следующего касания наступила, ответа нет  
**Применяется:** Когда `next_contact_date` ≤ сегодня и ответа нет

**Действия:**
1. Обновить статус в `leads_master.json` → `followup_due`
2. Подготовить черновик follow-up сообщения
3. Внести в `followup_queue` с `approval_required: true`
4. Уведомить Дмитрия для одобрения
5. После одобрения — отправка вручную

---

#### `hold_30d`
**Условие:** Клиент ответил нейтрально ("позже", "занят", "не сейчас")  
**Признаки:**
- "Напишите через месяц"
- "Сейчас не до этого"
- "Позже рассмотрим"

**Действия:**
1. Обновить статус → `hold_30d`
2. Установить `next_contact_date` = сегодня + 30 дней
3. Зафиксировать контекст в `notes`
4. Убрать из активной очереди до истечения срока

---

## 4. Что делать при молчании

**Ситуация:** Прошло 48+ часов с момента отправки, ответа нет

### 4.1 Для ZB23 (первый follow-up)

- **Дата проверки:** 2026-05-28
- **Статус:** `waitin_reply` → переход в `followup_due` при наступлении даты
- **Следующий канал:** WhatsApp Business
- **Действие:**
  1. 2026-05-28 утром — проверить почту
  2. Если ответа нет → статус `followup_due`
  3. Подготовить черновик WhatsApp-сообщения
  4. Внести в `followup_queue_2026-05-28.json`
  5. Уведомить Дмитрия → ждать одобрения
  6. После одобрения — отправить вручную через WhatsApp Business

### 4.2 Общее правило молчания

| После отправки | Действие |
|---|---|
| < 48 ч | Ничего не делать. Статус: `waiting_reply` |
| 48–72 ч | Проверить. Если нет ответа → статус `followup_due` → подготовить следующий канал |
| > 14 дней и 4–5 касаний без ответа | Статус `hold_30d` или снять с активного outreach |

## 5. Что делать при ответе "Пришлите"

**Ситуация:** Клиент проявил интерес, просит прислать информацию

### 5.1 Алгоритм

1. **Зафиксировать** ответ в `followup_queue` со статусом `reply_positive`
2. **Подготовить** коммерческое предложение / детальный план аудита
3. **"Пришлите" = горячий лид** — приоритет HIGH
4. **Выбрать формат ответа:**
   - Отвечаем на том же канале (Email если ответ по email)
   - Опционально: краткое КП + приглашение на звонок
5. **Черновик ответа** сохранить в `draft_path`
6. **Одобрение Дмитрия** → отправка не позднее 2–3 часов после получения запроса
7. **Зафиксировать** отправку в `outreach_log_*.md`

### 5.2 Шаблон ответа

Использовать: `02_templates/b2b_followup_message_templates.md` → раздел "Ответ на интерес"

## 6. Что делать при отказе

**Ситуация:** Клиент явно отказался от контакта или услуги

### 6.1 Алгоритм

1. **Уважительно принять** отказ — никаких повторных попыток
2. **Обновить статус** → `reply_negative`
3. **Установить** `do_not_contact: true`
4. **Добавить** в `data/lead_blacklist.json` при явном "не пишите больше"
5. **Не планировать** follow-up по этому лиду
6. **Зафиксировать** причину в `notes` для статистики
7. **Опционально:** если вежливый отказ ("сейчас не актуально") — можно перевести в `hold_30d` с условием

### 6.2 Варианты отказа и реакция

| Тип отказа | Статус | Действие |
|---|---|---|
| "Не интересно" | `reply_negative` | Закрыть лид |
| "Не пишите больше" | `reply_negative` + `do_not_contact: true` | Блэклист |
| "Сейчас не актуально" | `hold_30d` | Контакт через 30 дней |
| Нет ответа (unsubscribe/bounce) | `reply_negative` | Удалить из активных |
