📋 Как управлять системой сейчас

🎯 Роли инструментов

  • Dashboard (этот экран) — только смотреть состояние. Не выполняет действия.
  • Cline (VS Code) — давать команды на подготовку задач в AI_WORKSPACE. Черновики, логи, обновления статусов.
  • Ручная почта / WA / MAX / TG — отправлять клиентам только вручную, после Cline подготовит черновик.
  • После ручной отправки → Cline — залогировать касание командой log_manual_touch [лид].
  • Telegram-бот — пока не подключён к этим командам. Будет позже.
  • Auto-send — ВЫКЛЮЧЕН. Все отправки только вручную с approvaлом.

📥 Шаг 1 — Смотреть

  • Открыть dashboard (этот файл)
  • Найти нужного лида в очереди
  • Прочитать «Что решить» и команду

⚡ Шаг 2 — Дать команду Cline

  • Скопировать команду из блока лида
  • Вставить в Cline (VS Code)
  • Дождаться черновика / отчёта

✅ Шаг 3 — Залогировать

  • После ручной отправки → Cline
  • Команда: Залогируй ручное WA-касание ZB23
  • Cline запишет в outreach_log
