## Ключевые термины

### HOLD
**Значение:** Лид заморожен. Никаких действий до подтверждения.  
**Когда:** Нет контакта / нет актуального статуса / требует проверки.  
**Действие:** Дмитрий подтверждает вручную перед любым касанием.

### Legacy (Старый лид)
**Значение:** Лид, по которому последнее известное действие было давно (>7 дней) или не подтверждено.  
**По умолчанию:** HOLD / Нужна проверка.  
**Действие:** НЕ ДЕЙСТВОВАТЬ без верификации источника.

### Approval Gate (Ворота одобрения)
**Значение:** Блокировка, которую снимает только Дмитрий явным образом.  
**Применяется к:** любой отправке email / WhatsApp / PDF / Telegram.  
**Нарушение:** невозможно — автоотправка выключена (auto_send = false).

### Auto-send OFF (Автоотправка выключена)
**Значение:** Dashboard и скрипты не могут ничего отправить самостоятельно.  
**Статус:** Постоянный режим работы.  
**Отображение:** Красный badge в заголовке.

### Stale (Устаревшие данные)
**Значение:** dashboard_state.json старше 15 минут.  
**Симптом:** Красное предупреждение в верхней части dashboard.  
**Решение:** `node tools/dashboard/build_dashboard_state.mjs`

### Source-driven (Управляемый из источников)
**Значение:** Dashboard читает данные из JSON/MD файлов, а не содержит их жёстко в HTML.  
**Преимущество:** Обновил источник → перезапустил скрипт → dashboard обновился.
